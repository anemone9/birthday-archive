# Birthday Archive

一个可自定义的生日信件与礼物揭晓网站。访客可以打开生日信，再逐份查看礼物照片、提示文字和挑选理由。

## 功能

- 编辑封面标题、收件称呼、生日信与署名
- 添加、排序和自定义礼物
- 上传礼物照片，也可选择上传 GLB 模型
- 为每份礼物编辑拆开前的短提示和挑选理由
- 自定义进入最终庆祝页面的按钮文字
- 导出与导入本地备份
- 适配手机和桌面页面

## 本地运行

需要 Node.js 22.13 或更高版本。

~~~sh
npm ci
npm run dev
~~~

开发服务器默认在本机 5173 端口运行。生成正式构建时运行 npm run build。

## 内容与隐私

生日信、称呼、礼物理由和上传媒体保存在当前浏览器的 IndexedDB 中。网站链接本身不包含这些内容，数据不会因为上传源码而进入 Git 仓库。跨设备使用时，请在编辑页导出备份，再在另一台设备手动导入。

请勿提交生日档案备份、照片、GLB 文件、环境变量文件或凭据。仓库模板中的默认称呼和礼物名称都是通用示例。

## 发布设置

.openai/hosting.json 不包含原站点的项目编号。若使用 OpenAI Sites 发布，请先为自己的站点填写项目编号与所需绑定设置，再按 Sites 的发布流程操作。
